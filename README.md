# Civ V - Vanilla (Unciv Mod)

This is an Unciv mod repository that contains the Civ V - Vanilla ruleset from the main Unciv game.

## What is this?

This repository automatically syncs the built-in "Civ V - Vanilla" ruleset from the [Unciv game](https://github.com/yairm210/Unciv) and structures it as a standalone mod that can be used with Unciv.

## Source

The ruleset is automatically copied from: `android/assets/jsons/Civ V - Vanilla/` in the [Unciv repository](https://github.com/yairm210/Unciv).

## How it works

A GitHub Action runs daily to:
1. Clone the latest Unciv repository
2. Copy the Civ V - Vanilla ruleset files
3. Structure them in the Unciv mod format
4. Create a pull request with any updates

## Installation

To use this mod in Unciv, download it from the in-game mod browser or manually copy the contents to your Unciv mods directory.
